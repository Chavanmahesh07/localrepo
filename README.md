Syncing with GitHub (origin)

• git remote -v — Lists the remote repository URLs connected to your local project.
• git remote add origin <--repo-url> — Connects a local repository to an empty remote repository on GitHub.
• git push -u origin <--branch> — Uploads your local branch to GitHub and sets it as the default upstream target.
• git push — Pushes subsequent local commits to the tracked remote branch.
• git pull — Fetches changes from GitHub and merges them into your current local branch.
• git fetch — Downloads remote updates without automatically merging them into your local files.
